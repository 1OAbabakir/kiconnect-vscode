# Projektsymbol

`icon.svg` ist die bearbeitbare Vektordatei des für dieses Projekt erstellten Symbols. `icon.png` ist die daraus erzeugte 256 × 256 Pixel große Fassung für VS Code und den Marketplace.

Das Motiv verbindet Codeklammern und eine Verbindungslinie. Es enthält weder das Stadtwappen Dortmunds noch ein übernommenes Logo von KI:connect oder Microsoft. Es wird zusammen mit diesem Projekt unter der MIT-Lizenz bereitgestellt.

Die PNG-Datei kann bei installiertem ImageMagick neu erzeugt werden:

```bash
magick -background none assets/icon.svg assets/icon.png
```
